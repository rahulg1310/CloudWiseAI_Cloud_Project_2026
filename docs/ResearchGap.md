# Research Gap

Existing cloud cost optimization systems mainly focus on monitoring historical cloud usage or optimizing individual cloud services. Very few solutions combine AI-powered prediction, anomaly detection, optimization recommendations, and FinOps practices into a unified framework specifically designed for MSMEs. **Furthermore, many existing solutions lack proactive cost forecasting and early detection of unusual spending patterns, making it difficult for small businesses to prevent unexpected cloud expenses. MSMEs also require cost-effective, scalable, and easy-to-understand solutions that do not demand extensive cloud expertise.** Therefore, there is a need for an integrated, AI-driven cloud cost optimization framework that enables MSMEs to forecast future expenses, identify cost anomalies, and receive actionable optimization recommendations while maintaining a balance between cost efficiency and performance.

The proposed framework addresses these limitations by integrating machine learning, AWS services, and interactive dashboards to provide proactive cloud cost optimization.
