# Dataset Details

| Item | Value |
|---|---|
| Name | CloudWiseAI synthetic AWS billing dataset (CUR-style) |
| Source | Generated by `dataset/generate_dataset.py` (random seed 42); fields modelled on the AWS Cost and Usage Report |
| Location | `dataset/raw/cloudwise_billing.csv` and `dataset/raw/anomaly_labels.csv` |
| Size | About 1.1 MB |
| Records | 15,950 daily records: 25 resources x 638 days (1 Jan 2025 - 30 Sep 2026) |
| Features | 9 columns: date, billing_period, service, region, resource_id, usage_hours, storage_gb, avg_cpu_utilization, cost |
| Anomaly labels | 20 labelled anomalous resource-days forming 8 events (used only for evaluation) |
| Coverage | 7 AWS services (EC2, S3, RDS, CloudFront, Lambda, EBS, Data Transfer), 4 regions |
| Total spend | About $495,700 over 21 months |
| License | MIT (generated data, no third-party data) |
| Privacy | No personal or customer data |

The data is synthetic because no real MSME billing export was available. Real CUR exports can be mapped to the same columns; account IDs, tags and user names must be removed or masked first.
