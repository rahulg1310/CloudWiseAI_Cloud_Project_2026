## Read these before quoting the numbers

- **The data is synthetic.** The injected anomalies are large (2.2x to 4x) over 3.5% noise, which makes them easy to detect. A perfect score here does not predict performance on real billing data.
- **The forecast scores are optimistic by construction.** The generator builds costs from a linear trend, a weekday pattern and a yearly sine wave, and the ridge model fits exactly those terms. XGBoost adds nothing because there is no nonlinear structure left in the residuals.
- `confidence` in the API is `1 - backtest MAPE` at that horizon. It is measured historical accuracy, not a statistical confidence interval, and the UI labels it "backtest accuracy".
- To get honest numbers, run the same pipeline on a real AWS Cost and Usage Report with the same columns.
